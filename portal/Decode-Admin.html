Add a key for any provider you want to use. Keys are kept only in this browser. They are never written into this file and never sent anywhere except to the provider you choose.

Slow answers? Turn on two or three providers. In Spread mode every component goes to a different provider at the same time, and if one is busy the next one takes over. Press Test all & sort by speed to put the fastest first.

Anyone who can use this browser profile can read the saved keys. Do not save keys on a shared computer: untick "Remember keys" (they are then dropped when the tab closes). Generated code only ever runs inside a sandboxed preview that cannot read these keys.
